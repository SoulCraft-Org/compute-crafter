Purpose

Compute Crafter wires open-weight compute into the OpenCode Desktop App first and the Claude Desktop App second. It runs on free credits and flat monthly plans. It never uses pay-per-use billing.

It also gives each user a list of their plans, a list of their sign-ins and a score page, so the setup stays visible after the first day.

How it works

The plan catalog is owned by the compute-credits repo. This repo reads it and pins a checked copy. It never edits it.

The owner's decision

How wide should Compute Crafter stay?

OptionWhat it means
A. Stay narrow (recommended)Free tiers and flat plans for the two desktop apps. The catalog stays in its own repo.
B. Add self-hosted and API lanesGuides for running open weights yourself. This grows the page count and the re-read load.
C. Fold into the catalog repoOne repo for plans and guides. The desktop-app wiring loses its own home.

Why A: the repo already scores near the top on a narrow scope, and every new lane adds guides that need a vendor-page re-read each cycle.
