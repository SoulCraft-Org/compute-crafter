# Maintainers

| Maintainer | GitHub | Since | Can |
|---|---|---|---|
| [SoulCraft-Org owners](https://github.com/orgs/SoulCraft-Org/people) | The org's owner role | 2026 | Everything: merge any PR, promote to production, change these rules |

AI agents review and merge the orchestrator's own PRs. No outside PR is AI-mergeable yet: this repo has no `merge_policy.json` ([`GOVERNANCE.md`](GOVERNANCE.md)). Agents are not maintainers: they never approve a PR and never change the rules they follow.

To become one, see [`GOVERNANCE.md`](GOVERNANCE.md#the-maintainer-seat).
